# PRODUCT.md — AIHub（版本 A / impeccable）

## 一句话
AIHub 是一份**编目式的 AI 工具索引**：把 350+ 个 AI 模型、API 中转站与工具，整理成一本可以"翻阅"的、安静而有分量的目录。

register: brand（设计即产品 —— 这是一个导航/编目品牌站）

## 受众
中文开发者与 AI 从业者。他们见过太多花哨的 AI 导航站。我们要给的是**信任感**与**秩序感**——像翻开一本印制精良的设计年鉴的目录页，而不是又一个发光的 SaaS 落地页。

## 情绪场景（一句话定调）
"黄昏时分，一间设计档案室的阅览室——整个 AI 工具版图像一份排版考究的活字印刷目录摊在暖色纸面上，油墨的分量，没有任何东西在喧哗，但每一条都能被找到。"

## 设计哲学
- **Editorial（编辑感）**：这是一本"目录/索引"，不是卡片墙。信息有秩序、有节奏、有层级。
- **Warm（温暖）**：暖意来自纸张底色、陶土点缀色与衬线字体，而非渐变或发光。
- **Quiet（安静）**：用空间制造张力，不用颜色。一屏只说一两件事。
- **Confident（克制）**：极细发丝线、单色、适度圆角。每个元素都有存在的理由。

## 颜色策略
Committed-restrained。遵循 Anthropic 真实身份，**舍弃 palette 脚本给的靛紫种子**（与用户硬约束冲突）。
- `--paper` 暖纸底色 `oklch(0.970 0.006 90)` ≈ #faf9f5（非纯白，用户硬性要求）
- `--surface` 稍深纸面 `oklch(0.952 0.010 84)`（卡片/分区底）
- `--ink` 暖近黑 `oklch(0.255 0.012 70)`（正文，对纸面 >12:1）
- `--muted` 暖灰 `oklch(0.505 0.018 68)`（辅助信息，对纸面 ≈ 5.3:1，达标）
- `--clay` 陶土点缀 `oklch(0.635 0.115 44)` ≈ #c2683f（Anthropic 黏土色，用量 ≤10%）
- `--line` 发丝线 `oklch(0.885 0.010 80)`

## 字体（均不在 impeccable reject 名单内）
- 标题/展示：**Literata**（Google 为电子书设计的暖色书卷衬线，有光学尺寸，比 Fraunces 更有建筑感、更少陈词）+ CJK 回退 `Noto Serif SC` / `Songti SC`
- 正文：**Hanken Grotesk**（人文无衬线，温暖、克制）+ CJK 回退系统字体 `PingFang SC` / `Microsoft YaHei`
- 数字：`font-feature-settings: "tnum"` 等宽数字
- 对比轴：衬线 + 无衬线（正确配对），非两个相似无衬线。

## 反"编辑套路"防御（impeccable 警告的已饱和指纹）
1. 不用 Fraunces 斜体 → 用 Literata 正体 + 字重对比。
2. 不在每个分区上放 tiny uppercase tracked eyebrow（明令禁止）。
3. 编号 01–14 仅作为**真实的目录索引序列**（这本就是一本编目，编号是其组织系统本身，而非装饰）。
4. 不用三栏发丝线分隔的通用配方；用左重的不对称编目布局。
5. 不用相同卡片网格；分区内的链接以精炼的索引行呈现。

## 布局结构
- 非居中 hero：左重报头（masthead），右侧留白制造张力。
- 主体：编目式索引。每个分类是一个分区，链接以"索引行"呈现（名称 / 描述 / 站点），不是卡片墙。
- 不对称网格，编辑节奏：疏密交替。

## 动画（轻、克制、有意义、基于物理缓动）
- 载入：报头 → 索引行 measured stagger（ease-out-expo）。
- 滚动：增强已可见内容的细微 reveal，绝不用 class 门控可见性。
- 全程 `prefers-reduced-motion` 回退。
- 禁止：旋转、漂浮卡片、粒子、发光。

## 技术
单页 index.html，语义化 HTML，现代 CSS（OKLCH、clamp、container query 视情况），共享 data.js 渲染。无重型框架。可访问、响应式、性能优先。
